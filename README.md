# PortScanApp

PortScanApp is a basic Python-based GUI application for scanning open ports on a target IP address or domain.

## Features
- Simple Tkinter GUI with progress bar and status updates
- Customizable port range with multi-threaded scanning
- Banner grabbing for common services (HTTP, HTTPS, FTP, SSH, etc.)
- Export scan results to TXT, CSV, JSON, or XML formats
- Cancel scan functionality
- Real-time progress updates

## How to Run
```bash
python portscanapp.py
```

## Requirements
- Python 3.x

_No external libraries required for basic functionality._
